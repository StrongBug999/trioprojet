# Contribuer à TrioProjet

Merci de vouloir contribuer ! Ce projet se veut simple et accueillant :
toutes les contributions sont bienvenues, y compris les corrections de
fautes d'orthographe.

## Signaler un problème

Ouvrez une « Issue » sur GitHub en décrivant :
- ce que vous avez fait,
- ce que vous attendiez,
- ce qui s'est passé à la place (une capture d'écran aide beaucoup).

## Proposer une modification

1. Forkez le dépôt puis créez une branche : `git checkout -b ma-branche`
2. Faites vos modifications et committez : `git commit -m "Ajout de ma fonctionnalité"`
3. Poussez la branche : `git push origin ma-branche`
4. Ouvrez une « Pull Request » en décrivant ce qu'elle apporte

## Quelques règles simples

- Restez dans l'esprit du projet : **zéro dépendance**, zéro framework,
  zéro serveur. Du HTML, du CSS et du JavaScript suffisent.
- Gardez le code lisible et commenté là où ce n'est pas évident.
- L'interface est en français ; si vous ajoutez une langue, proposez un
  mécanisme de traduction plutôt que de dupliquer les pages.
- Testez vos modifications avant de proposer la Pull Request (ouverture de
  la page, répartition, copie du résultat).

## Idées de contributions

Jetez un œil à la feuille de route dans le [README](README.md), ou proposez
la vôtre en ouvrant une Issue avant de coder.
